# Mark Zuak — kişisel site

## Bilgisayarda açmak
`index.html` dosyasına çift tıklayarak tarayıcıda açabilirsin.

## Linkleri değiştirmek
`index.html` içindeki TikTok, Instagram ve Discord linklerini kendi hesaplarınla değiştir.

## Vercel'e yüklemek
1. GitHub'da yeni bir repository oluştur.
2. Bu klasördeki 4 dosyayı (`index.html`, `style.css`, `script.js`, `profile.png`) repository'ye yükle.
3. Vercel'e girip GitHub ile giriş yap.
4. "Add New..." → "Project" → repository'yi seç.
5. Framework Preset: Other / None bırak.
6. Deploy'a bas.
7. Birkaç saniye sonra sana `...vercel.app` adresi verir.
